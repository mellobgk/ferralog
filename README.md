# Ferralog — Sistema de Gestão de Ferramentas

Projeto acadêmico em linguagem C, inspirado nos exercícios de Algoritmos da UNIPÊ.

## Funcionalidades
- Cadastrar ferramenta (código, nome, setor, quantidade, preço e garantia)
- Listar e consultar ferramentas
- Registrar retiradas e devoluções com nome do responsável
- Consultar histórico de movimentações
- Gerar relatório de estoque
- Persistir dados em arquivos locais
